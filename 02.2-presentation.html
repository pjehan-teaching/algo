Présentation

Définition

Un ordinateur est une machine électronique qui fonctionne par la lecture séquentielle d'un ensemble d'instructions, organisées en programmes, qui lui font exécuter des opérations logiques et arithmétiques sur des chiffres binaires.

Exemple : Recette de cuisine 🥞

  1. Mettre la farine dans une terrine et former un puits.
  2. Y déposer les œufs entiers, le sucre, l'huile et le beurre.
  3. Mélanger avec un fouet en ajoutant au fur et à mesure le lait.
  4. Parfumer de rhum.
  5. Mettre de l'huile dans une poêle et faire cuire la pâte.

Exemple : Préparer un café ☕

  1. Mettre la capsule dans la machine.
  2. Appuyer sur le bouton de mise en marche.
  3. S'il n'y a plus d'eau, remplir le réservoir.
  4. Attendre que le café soit prêt.
  5. Prendre la tasse.

Exemple : Faire des courses 🛒

  1. Aller au supermarché.
  2. Prendre un chariot.
  3. Mettre des produits dans le chariot.
  4. Aller à la caisse.
  5. Tant qu'il reste des produits dans le chariot, les déposer sur le tapis roulant.
  6. Payer.
  7. Tant qu'il reste des produits sur le tapis roulant, les déposer dans le chariot.
  8. Aller à la voiture.
  9. Tant qu'il reste des produits dans le chariot, les déposer dans le coffre de la voiture.

Algorithme != Langage de programmation

Un algorithme n'est pas associé à un langage de programmation en particulier.

Il est donc possible, à partir d'un seul algorithme, d'écrire le code source correspondant dans différents langages.

Cependant, en fonction des spécificités d'un langage, un même algorithme ne pourra pas toujours s'appliquer (paradigme objet par exemple).

Fonctionnement d'un ordinateur

AlgoBox

Afin de vous familiariser avec les concepts de base de l'algorithmique, nous allons utiliser le logiciel AlgoBox.

Il s'agit d'un logiciel libre, gratuit et multiplateforme destiné à l'initiation à l'algorithmique.

Nous utiliserons ce logiciel dans un premier temps avant d'utiliser un langage de programmation afin de nous focaliser sur l'algorithmique plutôt que sur la syntaxe d'un langage spécifique.

Indentation

L'indentation consiste en l'ajout de tabulations ou d'espaces dans un fichier, pour une meilleure lecture et compréhension du code.

Dans l'exemple ci-dessous, le code de gauche n'est pas indenté tandis que celui de droite est correctement indenté :

int main (int argc, char *argv[])
{
int variable;
variable = 2;
if (variable > 3)
{
printf("Hello world!\n");
}
return 0;
}
int main (int argc, char *argv[])
{
    int variable;
    variable = 2;
    if (variable > 3)
    {
        printf("Hello world!\n");
    }
    return 0;
}
AlgoBox fera l'indentation automatiquement

Accolades

Il existe en règle générale deux façons d'écrire les accolades. On pourra opter pour l'une ou pour l'autre en fonction de ses préférences personnelles, mais aussi du langage de programmation utilisé. 

int main (int argc, char *argv[])
{
    int variable;
    variable = 2;
    if (variable > 3)
    {
        printf("Hello world!\n");
    }
    return 0;
}
int main (int argc, char *argv[]) {
    int variable;
    variable = 2;
    if (variable > 3) {
        printf("Hello world!\n");
    }
    return 0;
}
AlgoBox fera automatiquement l'instruction de début/fin d'un bloc

Interlignes et espaces

Il est important de laisser des espaces entre les différents éléments d'un programme afin de le rendre plus lisible. On pourra par exemple ajouter des espaces : 

int main (int argc, char *argv[])
{
    int variable;
    variable = 2;

    if (variable > 3)
    {
        printf("Hello world!\n");
    }

    return 0;
}
int main (int argc, char *argv[])
{
    int variable;
    variable = 2;
    if (variable > 3)
    {
        printf("Hello world!\n");
    }
    return 0;
}

Commentaires

Les commentaires sont des éléments du code qui ne seront pas interprétés par l'ordinateur. Ils permettent d'ajouter des informations supplémentaires dans le code afin de le rendre plus lisible. 

/**
 * Fonction principale de mon programme
 * @param int argc Le nombre d'arguments
 * @param char* argv Les arguments passés en paramètre
 * @return int
 */
int main(int argc, char *argv[])
{
   int variable;
   variable = 2;
   // Si ma variable est supérieure à 3
   if (variable > 3)
   {
      printf("Hello world!\n"); // Affiche Hello world! dans la console
   }
   return 0;
}
